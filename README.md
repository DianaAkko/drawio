# DrawIO

A diagram and chart drawing application.

## Features

- Create and edit diagrams
- Support for various diagram types
- Export in multiple formats

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Project Structure

```
.
├── src/          # Source code
├── public/       # Static assets
├── dist/         # Build output
└── docs/         # Documentation
```
